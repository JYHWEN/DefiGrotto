# DefiGrotto

Runs a local testing environment for decentralized finance (DeFi) applications with simulated data and live network connections.

DefiGrotto is built to be simple and practical, focusing on doing one thing well.

**Why DefiGrotto?**

- Runs a local testing environment
- for decentralized finance (DeFi) applications
- with simulated data and live

## Key Features

- Runs a local testing environment
- for decentralized finance (DeFi) applications
- with simulated data and live

## Technology Stack

- typescript
- typescript framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/DefiGrotto.git`
2. `cd DefiGrotto`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
